# ChatGPT Connection

ChatGPT is optional. Gmail remains a complete fallback owner interface.

Where custom Actions/API connectivity is available, import `action-openapi.yaml`, replace the server URL and configure API-key authentication using `X-DealOS-Key`.

If your plan/workspace does not support this interface, use ChatGPT for strategy separately and use the weekly Gmail digest for live approvals. Do not make unattended DealOS execution dependent on a ChatGPT tab staying open.
