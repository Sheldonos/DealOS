# Optional Voice / Meeting Autonomy

Email-first is the lowest-cost and lowest-risk default. Some deals will insist on live calls. If those calls threaten the <=60-min/week owner budget, add a disclosed AI phone/meeting agent only after the email system is converting.

Recommended architecture: **Twilio or a managed voice-agent platform + OpenAI Realtime**, connected to DealOS through a narrow webhook. The voice agent may qualify, answer approved factual questions, schedule follow-up, and create notes. It must not sign, accept nonstandard legal terms, state unverified claims, or conceal required AI/recording disclosures.

Before enabling, configure jurisdiction-specific call-recording/AI disclosure rules and give callers a path to a human. Do not deploy autonomous cold-calling merely to increase volume; add voice only where qualified opportunities require it.
