# IBM Bob Skills Implementation Package

This skill serves as the central routing and architectural guide for an IBM Project Bob environment equipped with 38 specialized capabilities. It does not perform a single atomic action; rather, it provides the operational blueprint for orchestrating these skills into a relentless, autonomous enterprise workforce.

## Core Architecture

To manage this level of complexity, you must operate within a hierarchical agent structure.

| Core Skill | Purpose in Architecture |
| --- | --- |
| `master-orchestrator` | Use this skill first to decompose high-level user requests into actionable tasks and route them to the appropriate domains below. |
| `agentic-systems-architect` | Use this to define the communication protocols between the sub-agents handling different domains. |
| `agent-lifecycle-manager` | Use this to dynamically spawn parallel agents when workloads require it (e.g., generating 1,000 leads). |

## Operational Domains

When the Master Orchestrator routes a task, it should direct it to one of the following domains.

## Orchestration Workflows

When a user requests a complex outcome, chain these skills together.

| Workflow Name | Execution Sequence |
| --- | --- |
| **The "Idea to IPO" Workflow** | Route the raw idea to `startup-builder-architect` for qualification. Pass the output to `ibm-solution-architect-web` for C4 diagrams and requirements. Hand those artifacts to `full-stack-app-developer` and `relentless-developer` for execution. |
| **The "Enterprise Deal" Workflow** | Use `independent-megadeal-originator` to find the target. Use `enterprise-sales-playbook` to structure the pitch. Use `ibm-bob-whiteboard-storyboard` to generate the visual deck. |
| **The "Creative Campaign" Workflow** | Define the strategy with `psychopolitical-campaign-manager`. Write the script with `master-storytelling`. Generate visuals with `amir-mushich-prompt-writer` and `video-generator`. Generate audio with `music-prompter` and `tts-prompter`. |
