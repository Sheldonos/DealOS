# Animated Series Producer (Amir Mushich Framework Edition)

This skill provides a structured workflow for transforming a raw script and character reference images into a complete, production-ready instruction manual for AI video generation tools (like Kling AI, Veo 3, or Hailuo).

Crucially, this skill utilizes the **Amir Mushich 5-Phase Directing Framework** to generate prompts. Instead of flat, descriptive prompts, it generates comprehensive "Director's Briefs" that instruct the AI to act as a Master Animation Director, ensuring cinematic, high-end, and emotionally resonant outputs.

## Core Workflow

When a user requests to break down a script for an animated series using this skill, follow these steps in order:

### Step 1: Analyze the Inputs

1. Read the provided script using the `file` tool.

1. View the provided character reference images using the `file` tool (with multimodal capabilities).

1. Identify the core characters, settings, and the overall visual style implied by the references.

### Step 2: Break Down the Script into Scenes

1. Divide the script into distinct scenes or shots (typically 5-10 seconds of action each).

1. For each scene, extract:
  - **Setting/Location:** Where the scene takes place.
  - **Characters Present:** Who is in the shot.
  - **Action:** What happens in the shot.
  - **Dialogue:** Any spoken lines (if applicable).

### Step 3: Generate Amir Mushich 5-Phase Director Briefs

1. For each scene, construct a highly detailed, 5-phase director brief optimized for AI video generators.

1. The prompt MUST follow this exact structure:
  - **Variable Declaration:** `[SCENE]`, `[SUBJECT]`, `[AESTHETIC]`
  - **Role Assignment:** `Act as a Master Animation Director...`
  - **PHASE 1: SEMANTIC INTELLIGENCE (AUTONOMOUS):** Character and environment design instructions.
  - **PHASE 2: COMPOSITIONAL STRUCTURE & FRAMING:** Camera, positioning, and depth.
  - **PHASE 3: GRAPHIC ELEMENTS & LINEWORK:** Style, linework, and tactile details.
  - **PHASE 4: LIGHTING, COLOR & TEXTURE:** Lighting, palette, and atmosphere.
  - **PHASE 5: TECH SPECS:** Resolution and render quality.

1. Format these prompts clearly in a Markdown document so the user can easily copy them.

### Step 4: Generate Start and End Keyframes

1. Use the `generate` tool to create two images for *each* scene:
  - **Start Frame:** The initial state of the scene.
  - **End Frame:** The final state of the scene after the action has occurred.

1. **Crucial:** You MUST use the user's provided character reference images as image prompts/references within the `generate` tool to ensure the generated keyframes perfectly match the established character designs.

1. Save these generated images to a structured directory (e.g., `/home/ubuntu/project_name/keyframes/scene_1_start.png`).

### Step 5: Compile the Instruction Manual

1. Create a comprehensive Markdown document (e.g., `Production_Manual.md`).

1. Include the scene breakdown, the 5-phase director briefs, and embed the generated start/end keyframes for each scene.

1. Provide clear instructions to the user on how to use this manual with their preferred AI video generator.

## Important Considerations

- **The Director Mindset:** The prompts generated by this skill are not just descriptions; they are instructions to an AI acting as a world-class director.

- **Consistency is Key:** Always reference the original character images when generating new frames.

- **Pacing:** Keep scenes relatively short (representing 5-10 seconds of video) as current AI video tools struggle with long, complex actions in a single generation.
