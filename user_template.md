# PART 10 — CONNECTOR PERMISSIONS

## 10. What Can the Systems Do?

Use one level for every connected tool.

### Permission Levels

**0 — Off**  
Do not use it.

**1 — Read**  
The system can see data but cannot change anything.

**2 — Draft**  
The system can prepare work but cannot send or publish it.

**3 — Approval**  
The system can act after a person approves it.

**4 — Bounded Auto**  
The system can act on its own inside clear limits.
